# JobIntel AI local MVP

Документацию ведите по-русски. Исходный brief и прежние контракты сохранены в Git истории на main; текущая область и честные ограничения находятся в docs/scope.md. Не объявляйте synthetic provider реальным inference.

Запуск: `make run`; проверки: `make check`, `make build`. Приложение слушает только 127.0.0.1. Не добавляйте автоматический URL fetch, платные вызовы в тесты, публикацию приватных данных или startup миграцию прежней БД. Не перезаписывайте исходные данные. Для изменений UI проверьте desktop/mobile и ошибку/восстановление.
